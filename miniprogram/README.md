# 前端面试题小程序

一个微信小程序，包含前端面试题的完整汇总，分为基础版和进阶版。

## 项目结构

```
miniprogram/
├── app.js              # 小程序入口
├── app.json            # 小程序配置
├── app.wxss            # 全局样式
├── project.config.json # 项目配置
├── sitemap.json        # 站点地图
├── pages/              # 主包页面
│   └── index/          # 首页
├── packageBasic/       # 基础面试题分包
│   ├── pages/
│   │   └── content/    # 内容展示页
│   └── data/           # 面试题数据
├── packageAdvanced/    # 进阶面试题分包
│   ├── pages/
│   │   └── content/    # 内容展示页
│   └── data/           # 面试题数据
└── assets/             # 图标资源
```

## 功能特点

- ✅ **TabBar导航**：两个tab分别展示基础面试题和进阶面试题
- ✅ **章节分类**：按章节分类展示面试题
- ✅ **搜索功能**：支持题目和内容搜索
- ✅ **分包加载**：采用分包处理，优化加载速度
- ✅ **懒加载**：点击加载更多，提升首屏速度

## 使用方法

### 1. 安装微信开发者工具

从 [微信官网](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html) 下载并安装微信开发者工具。

### 2. 导入项目

1. 打开微信开发者工具
2. 选择"导入项目"
3. 项目目录选择 `miniprogram` 文件夹
4. AppID 使用: ``

### 3. 编译运行

点击工具栏的"编译"按钮，即可在模拟器中预览小程序。

## 数据来源

- 基础面试题：368道
- 进阶面试题：159道

## 数据更新

如果需要更新面试题数据：

1. 修改根目录下的 `前端面试题完整汇总.md` 和 `进阶面试题汇总.md`
2. 运行 `python3 parse_questions.py` 重新生成数据
3. 重新编译小程序

## 技术栈

- 微信小程序原生开发
- 分包加载
- 懒加载
- 本地JSON数据

## 注意事项

1. 小程序主包限制为 2MB，单个分包限制为 2MB，总大小限制为 20MB
2. 当前项目总大小约 500KB，完全符合限制
3. 使用了分包加载，优化了首屏加载速度
4. 支持搜索和章节筛选功能
