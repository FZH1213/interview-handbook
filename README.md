# 前端面试题小程序

基于 [interview.poetries.top](https://interview.poetries.top) 的前端面试题整理，微信小程序版本。

## 数据统计

- **基础面试题**: 538道 (莫兰迪蓝色系)
- **进阶面试题**: 173道 (莫兰迪粉色系)
- **总计**: 711道面试题

## 功能特性

- 章节分类筛选
- 全文搜索
- 懒加载优化
- 双色莫兰迪主题

## 项目结构

```
miniprogram/
├── app.js              # 小程序入口
├── app.json            # 配置文件
├── pages/
│   ├── index/         # 首页
│   ├── basic/         # 基础面试题
│   └── advanced/      # 进阶面试题
├── packageBasic/data/  # 基础题数据
└── packageAdvanced/data/ # 进阶题数据
```
